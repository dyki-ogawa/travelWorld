# ✈️ 旅行ログ - 海外旅行記録アプリ

海外旅行履歴を国単位で素早く記録・見返しできるWebアプリケーション（v0.1）

## 概要

「旅行ログ」は、過去の海外旅行を「いつ・どこ」で記録し、月1回の見返しで記憶を再点灯させるための軽量アプリです。
完全ローカル動作（IndexedDB）で、バックエンド不要、オフラインでも使えます。

### 主な機能（v0）

- ✅ 旅行記録の作成・編集・削除（国・期間・メモ）
- ✅ 国旗Emojiと国名での見やすい一覧表示
- ✅ 検索（国名）とソート（最新訪問順・国名順）
- ✅ 詳細ビュー（訪問記録 + 国の基本情報）
- ✅ JSONエクスポート/インポート機能
- ✅ 完全オフライン対応（IndexedDB）
- ✅ レスポンシブデザイン

## 技術スタック

- **フレームワーク**: React 18 + TypeScript
- **ビルドツール**: Vite
- **ストレージ**: IndexedDB (idb ライブラリ)
- **スタイル**: CSS (CSS Variables)

## 使い方

### 1. 初回：旅行を記録する

1. ホーム画面で「+ 新規作成」ボタンをクリック
2. 国を選択（検索可能・213カ国対応）
3. 訪問日を入力（必須）
4. 滞在日数を入力（任意・例: 3）
5. メモを入力（任意）
6. 「記録する」ボタンで保存

### 2. 記録を見返す

- ホーム画面で旅行カードをクリックすると詳細が表示されます
- 国旗・国名・期間・メモ・国の基本情報を確認できます

### 3. 検索とソート

- 検索バー：国名で絞り込み
- ソート：「最新訪問順」または「国名順（A→Z）」

### 4. データのバックアップ

1. 右上の「⚙️ 設定」ボタンをクリック
2. 「エクスポート」でJSONファイルをダウンロード
3. 「インポート」で以前のデータを復元

## データ構造

### Trip（旅行記録）

```typescript
type Trip = {
  id: string;          // uuid
  country_iso2: string;// "FR"（ISO 3166-1 alpha-2）
  start_date: string;  // "2019-05-01" (YYYY-MM-DD)
  days?: number;       // 滞在日数（任意）
  note?: string;       // 一言メモ
  created_at: number;  // epoch ms
  updated_at: number;  // epoch ms
};
```

### Country（内蔵国データ）

```typescript
type Country = {
  iso2: string;        // "FR"
  name_en: string;     // "France"
  name_ja?: string;    // "フランス"
  emoji: string;       // "🇫🇷"
  region?: string;     // "Europe"
};
```

世界213カ国・地域のデータを内蔵しています（ISO 3166-1準拠）：
🌏 アジア（50カ国） 🌍 ヨーロッパ（47カ国） 🌎 南北アメリカ（35カ国） 🌍 アフリカ（54カ国） 🌏 オセアニア（14カ国）
日本語名・英語名の両方で検索可能
